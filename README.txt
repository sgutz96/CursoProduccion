Sitio estático del curso Diseño de Proyectos Multimedia.

Para publicar: subir el contenido de esta carpeta (index.html, styles.css, images y clase-01 a clase-16) a cualquier hosting estático, por ejemplo GitHub Pages, Netlify o Vercel. No requiere instalación ni servidor.

Estructura: index.html es el home; cada clase está en clase-XX/index.html y comparte styles.css e images.
